# 動画DL

iPhone から、ネット上の動画を何件でもまとめてダウンロードできるアプリです。

- URL を貼り付けるだけで使えます。改行で区切れば何件でも入れられ、2件ずつ並行してダウンロードします。
- YouTube、X(Twitter)、TikTok、Instagram、ニコニコ動画、Vimeo など、[yt-dlp](https://github.com/yt-dlp/yt-dlp) が対応している1000以上のサイトで使えます。
- 対応サイト以外でも、ページの中にある `<video>`、mp4、m3u8(HLS) を自動で探してダウンロードします。
- 「iPhone用」を選ぶと、写真アプリでそのまま再生できる mp4(H.264/AAC) で保存されます。
- 「最高画質」と「音声のみ(m4a)」も選べます。
- Netflix などのDRM（コピー防止）付き動画には対応していません。

## しくみ

```
iPhone (Safari / ホーム画面のアイコン)
   │  URLを送る・できたファイルを受け取る
   ▼
PC かサーバー（このアプリ + yt-dlp + ffmpeg）── 動画サイト
```

iPhone のアプリは、iPhone の中で動画の解析や変換ができないように制限されています。
そのため、ダウンロード処理は PC（または自宅サーバー）で行い、iPhone からはアプリのような画面で操作する形にしています。
**自宅の PC で動かすのがおすすめです。** クラウドサーバーから YouTube にアクセスすると、ボット扱いでブロックされやすいためです。

## 1. 起動する（どれか1つ）

### A. Docker で起動（Mac / Windows / Linux）

```sh
cd video-downloader
APP_PASSWORD=好きなパスワード docker compose up -d --build
```

### B. Mac で起動

```sh
brew install python ffmpeg deno
cd video-downloader
APP_PASSWORD=好きなパスワード ./start.sh
```

### C. Windows で起動

1. [Python](https://www.python.org/downloads/) をインストールします（「Add to PATH」にチェックを入れる）。
2. PowerShell で `winget install ffmpeg` と `winget install DenoLand.Deno` を実行します。
3. `start.bat` をダブルクリックします。

起動すると、ターミナルに `http://192.168.x.x:8000` のようなアドレスが表示されます。

## 2. iPhone で開く

1. iPhone を PC と**同じ Wi-Fi** につなぎます。
2. Safari で、さきほどのアドレスを開きます。
3. 画面下の共有ボタンから「**ホーム画面に追加**」を選びます。これでアプリのアイコンができます。
4. パスワードを設定した場合は、右上の ⚙︎ から入力します。

## 3. 使い方

1. 動画ページの URL を貼り付けて「**ダウンロード**」を押します（何件でもOK）。
2. 完了したら「**iPhoneに保存**」を押し、もう一度押すと共有シートが出ます。
   - 「**ビデオを保存**」を選ぶと写真アプリに保存されます。
   - 「**"ファイル"に保存**」を選ぶとファイルアプリに保存されます。
3. 「ファイルに直接」を押すと、Safari のダウンロード機能でファイルアプリに保存されます。大きいファイルはこちらが確実です。

### 共有ボタンから一発で送る（ショートカット）

ショートカットアプリで次のショートカットを作ると、YouTube などのアプリの「共有」から直接ダウンロードを始められます。

1. ショートカット → 「＋」 → 詳細(i)で「**共有シートに表示**」をオンにし、受け取る種類を「URL」にします。
2. アクション「**URL**」を追加して、次のように入力します。
   `http://192.168.x.x:8000/?auto=1&url=` の後ろに変数「**ショートカットの入力**」を入れます。
3. アクション「**URLを開く**」を追加します。

## 外出先（モバイル回線）から使いたい場合

[Tailscale](https://tailscale.com/)（無料）を PC と iPhone の両方に入れてください。
同じ Wi-Fi にいなくても `http://PCの名前:8000` でアクセスできるようになります。
ルーターのポートを開けてインターネットに公開する方法はおすすめしません。どうしても公開する場合は、必ず `APP_PASSWORD` を設定してください。

## ログインが必要なサイト（会員限定・年齢制限など）

1. PC のブラウザでそのサイトにログインします。
2. 拡張機能「Get cookies.txt LOCALLY」などで `cookies.txt` を書き出します。
3. 環境変数 `COOKIES_FILE=/パス/cookies.txt` を付けて起動します。

## 設定（環境変数）

| 名前 | 内容 | 既定値 |
|---|---|---|
| `APP_PASSWORD` | アクセス用パスワード | なし（誰でも使える） |
| `MAX_PARALLEL` | 同時にダウンロードする件数 | 2 |
| `DOWNLOAD_DIR` | 保存先フォルダ | `./downloads` |
| `COOKIES_FILE` | ログイン用 cookies.txt のパス | なし |

## うまくいかないとき

- **急にダウンロードできなくなった**：サイトの仕様変更が原因のことが多いです。アプリを再起動すると yt-dlp が最新版に更新されます。
- **YouTube だけ失敗する**：`deno` が入っているか確認してください。
- **写真アプリに保存できない**：「最高画質」で保存したファイルは、iPhone が対応していない形式(VP9/AV1)のことがあります。「iPhone用」で保存し直してください。

## 注意

YouTube など多くのサイトは、利用規約でダウンロードを禁止しています。
また日本では、違法にアップロードされたものと知りながら動画をダウンロードすることは違法です。
自分の動画、フリー素材、権利者が許可しているものなどに使ってください。
